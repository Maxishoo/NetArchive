# Описание

**NetArchive** — мобильное приложение для поддержания слабых связей. Многие специалисты теряют ценные связи из-за отсутствия удобного инструмента для регулярного поддержания контактов: они забывают важные детали общения, пропускают поводы для взаимодействия и упускают карьерные возможности. Приложение решает эту проблему с помощью метода «картотеки» — фиксации взаимодействий, системы проактивных напоминаний и интеграции с сервисами планирования, такими как Google Calendar.

Идея приложения заключается в том, чтобы превратить случайные знакомства в стратегические долгосрочные связи. В отличие от традиционных сервисов для хранения контактов, таких как Google Contacts или LinkedIn, которые выполняют в основном функцию пассивного хранения информации, приложение предлагает системный подход к управлению профессиональными отношениями.

Дополнительным преимуществом является встроенный ИИ-ассистент, который анализирует записи о контактах и предлагает подсказки для содержательного общения. Данный подход позволит повысить вовлечённость пользователей в системное развитие своей сети и улучшить качество профессионального нетворкинга.

# Ключевые возможности

## Управление контактами нового поколения
- **Детализированные профили**: фиксируйте не только имя и номер, но и контекст знакомства, сферу деятельности, ключевые интересы и историю взаимодействий
- **Журнал взаимодействий**: ведите хронологию встреч, звонков и сообщений для каждого контакта — ни одна важная деталь не будет упущена
- **Быстрый поиск и фильтрация**: находите нужные контакты по имени, компании, тегам или дате последнего взаимодействия

## Интеллектуальная система напоминаний
- **Гибкое планирование**: устанавливайте разовые и повторяющиеся напоминания с привязкой к дате, времени и конкретному контакту
- **Фоновая доставка**: надёжная система уведомлений на базе Android WorkManager гарантирует своевременное оповещение даже при закрытом приложении
- **Умные подсказки**: ИИ-ассистент на базе YandexGPT анализирует историю общения и предлагает релевантные темы для возобновления диалога

## Аналитика профессиональной сети
- **Визуальная статистика**: отслеживайте динамику взаимодействий, активность контактов и эффективность нетворкинга
- **Инсайты для развития**: получайте рекомендации по укреплению слабых связей и выявлению перспективных направлений для профессионального роста
- **Экспорт данных**: формируйте отчёты для личного анализа или презентации руководству

## Безопасность и приватность
- **Локальное шифрование**: все данные хранятся в зашифрованной базе SQLite с использованием SQLCipher
- **Контроль доступа**: приложение запрашивает минимально необходимые разрешения, а чувствительные операции требуют подтверждения
- **Автономная работа**: основные функции доступны без подключения к интернету, синхронизация с облаком опциональна

## Интеграции и автоматизация
- **Поддержка календарей**: синхронизация напоминаний с внешними сервисами планирования
- **QR-кодирование**: быстрый обмен контактами через сканирование или генерацию кодов
- **API-расширяемость**: модульная архитектура позволяет легко добавлять новые интеграции и функции

# Техническая архитектура

NetArchive построен на современных стандартах Android-разработки с акцентом на масштабируемость, тестируемость и производительность.

## Стек технологий
- **Язык**: Kotlin 2.0+
- **UI**: Jetpack Compose с Material Design 3
- **Архитектура**: Clean Architecture + MVVM
- **DI**: Hilt для управления зависимостями
- **Навигация**: Navigation Compose с типобезопасными маршрутами
- **База данных**: Room Persistence Library с поддержкой SQLCipher для шифрования
- **Сеть**: Retrofit 2 + OkHttp 4 с Kotlinx Serialization
- **Фоновые задачи**: WorkManager для надёжного планирования напоминаний
- **ИИ-интеграция**: YandexGPT API через Retrofit-клиент с конфигурацией через Gradle properties

## Структура проекта
```
app/
├── data/
│   ├── local/          # Room entities, DAOs, database
│   ├── remote/         # Retrofit services, AI integration
│   ├── mapper/         # Преобразование между слоями данных
│   └── repository/     # Реализация репозиториев
├── domain/
│   ├── model/          # Бизнес-модели
│   └── usecase/        # Сценарии использования
├── ui/
│   ├── components/     # Переиспользуемые UI-компоненты
│   ├── navigation/     # Конфигурация навигации
│   ├── screens/        # Экраны приложения
│   └── theme/          # Тема и стили
├── di/                 # Hilt-модули для внедрения зависимостей
├── worker/             # Воркеры для фоновых задач
├── receiver/           # Broadcast receivers для системных событий
└── utils/              # Вспомогательные утилиты и хелперы
```

## Ключевые решения
- **Типобезопасная навигация**: маршруты определены через sealed class Routes, что исключает ошибки при передаче аргументов
- **Асинхронность**: корутины и Flow для реактивного управления состоянием и фоновыми операциями
- **Модульность**: чёткое разделение ответственности между слоями упрощает тестирование и развитие кода
- **Конфигурация через окружение**: чувствительные данные (API-ключи) вынесены в gradle.properties и не попадают в репозиторий

## Конфигурация ИИ-функций
Для активации ИИ-ассистента необходимо:
- Получить доступ к YandexGPT API через Yandex Cloud
- Настроить IAM-токен с правами на вызов языковой модели
- Указать идентификатор каталога и API-ключ в конфигурации приложения
